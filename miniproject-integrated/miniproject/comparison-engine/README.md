# Member 2 – Historical Webpage Comparison

This package extends the reference project with a cleaner, repeatable pipeline for comparing two HTML snapshots.

## Features
- Converts HTML into a structured JSON tree.
- Finds probable structural matches between versions.
- Detects additions, removals, and modifications.
- Stores intermediate trees and final JSON reports.
- Provides a single command-line entry point.

## Installation
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

## Run
```bash
python run_pipeline.py path/to/version1.html path/to/version2.html --output output
```

The output directory contains `tree_v1.json`, `tree_v2.json`, structural matching data, `changes.json`, and `run_summary.json`.

## Local API bridge

Install the requirements, then run:

```bash
uvicorn api:app --reload --host 127.0.0.1 --port 8000
```

`POST /api/compare` accepts multipart fields named `version1` and `version2`.
The wrapper calls the existing engine functions directly and uses
`result_adapter.py` only to convert their raw output for the React dashboard.

## Workflow
1. Read and normalize both HTML documents.
2. Build hierarchical trees containing tags, text, attributes, and children.
3. Match likely corresponding nodes using tag, text, attributes, and structure.
4. Compare matched nodes and identify additions, removals, and modifications.
5. Save machine-readable JSON results for later AI-assisted summarization.

## Limitations
- Dynamic content generated by JavaScript is not executed.
- Matching is heuristic and can be affected by major layout changes.
- Semantically equivalent but differently written HTML may be reported as modified.
- The pipeline is intended for archived snapshots, not security auditing.
